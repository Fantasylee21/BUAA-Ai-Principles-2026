# QLoRA SFT v4：冲突样本两倍过采样实验

> 来源：训练执行者提供的《多模态情感分析中的冲突样本过采样实验》材料，
> 于 2026-10-17 整理入库。训练配置和采样实现已对照仓库；本文的 v4 训练完成情况、
> 验证指标和测试预测完整性来自该材料，当前仓库尚未附对应 v4 原始日志、逐轮指标
> JSON 或完整测试产物，未在本机重新训练或独立复评。v3 对照见 [v3 报告](qlora_sft_v3.md)。

## 一、实验目的

多模态情感分析需要综合视频画面、文本和语音判断情绪。当不同模态提供的情感线索发生冲突时，模型还应表达不确定性，并提出澄清问题。训练数据中的一致样本（Aligned）数量较多，冲突样本（Conflict）占比较低，因此，本实验在 v3 的任务损失加权方法上加入冲突样本过采样，考察增加冲突样本的训练频率能否改善情感分类、不确定性判断及综合表现。实验选用 Qwen2.5-Omni-3B、Qwen3-VL-4B 和 Qwen2.5-VL-3B，以 v3 作为对照，比较三种模型对同一采样策略的响应。

## 二、实验方法与设置

实验沿用清洗后的完整训练数据。两个 VL 模型按有效视觉—文本输入去除配对重复记录，共保留 2,104 条；Omni 模型保留 VT、VA 两类输入，共 3,354 条。VT 表示视频与文本输入，VA 表示视频与音频协议。训练时，VL 使用视频与提供的文本，Omni 的 VA 样本还使用音频。验证和测试沿用统一的评估规则：VT 使用视频与文本；VA 对 VL 只提供视频画面，对 Omni 提供视频和音频。每条冲突样本沿用 v3 选定的一条澄清问题，保证比较过程中监督内容一致。

v4 将训练集按冲突标签分为两组，保留全部原始样本，再从 Conflict 组中有放回抽样，使其总条数达到原来的两倍；Aligned 组数量保持不变。重复样本在数据加载时确定，后续各轮对训练数据进行洗牌。该操作增加了已有冲突样本的出现频率，采样前后的数据分布如下。

| 数据类型 | Aligned 条数 | Conflict 条数（v3 → v4） | 总训练条数（v3 → v4） | Conflict 占比（v3 → v4） |
| --- | ---: | ---: | ---: | ---: |
| VL | 1,726 | 378 → 756 | 2,104 → 2,482 | 17.97% → 30.46% |
| Omni | 2,913 | 441 → 882 | 3,354 → 3,795 | 13.15% → 23.24% |

三个模型均从各自的预训练基座开始，使用 NF4 4-bit QLoRA 进行监督微调，冻结模态编码器与多模态投影层。LoRA 秩为 16，缩放系数为 32，dropout 为 0.05；学习率为 0.0001，单设备批大小为 1，梯度累积为 16，训练 3 轮，随机种子为 42。训练采用 BF16 和 FlashAttention 2，在 NVIDIA L40S 48 GB 上完成。v4 保留 v3 的任务损失设置，对每条回答中的情感字段、不确定性字段和其余内容分别计算平均损失，再按下式组合：

$$
L = 0.5 L_{\mathrm{emotion}} + 0.4 c(y)L_{\mathrm{uncertainty}} + 0.1 L_{\mathrm{rest}}.
$$

其中，冲突样本的 $c(y)=2$，一致样本的 $c(y)=1$。因此，v4 同时采用冲突样本过采样和不确定性字段加权。验证集保持完整的 666 条，其中 Conflict 为 74 条、Aligned 为 592 条；每轮训练结束后均进行完整生成式验证，并按综合分数选择最终模型。情感分类使用 positive、negative、neutral 三分类 Macro-F1；验证集真值包含 positive 和 negative，Macro-F1 仍按三分类计算。冲突识别准确率统计 Conflict 样本中输出不确定的比例，一致样本校准率统计 Aligned 样本中输出确定的比例。综合分数为：

$$
\mathrm{Score}=0.5\operatorname{MacroF1}+0.3A_{\mathrm{conflict}}+0.2A_{\mathrm{aligned}}.
$$

## 三、实验结果

三个模型均完成了 3 轮训练和各轮验证，最佳结果都出现在第 3 轮。下表列出 v3 与 v4 各自最佳模型的完整指标，数值保留四位小数。

| 模型 | 版本 | Macro-F1 | 冲突识别准确率 | 一致样本校准率 | 综合 Score |
| --- | --- | ---: | ---: | ---: | ---: |
| Qwen2.5-Omni-3B | v3 | 0.6340 | 0.7432 | 0.9443 | **0.7288** |
| Qwen2.5-Omni-3B | v4 | 0.6369 | 0.6892 | 0.9662 | 0.7185 |
| Qwen3-VL-4B | v3 | 0.6185 | 0.7568 | 0.9189 | **0.7201** |
| Qwen3-VL-4B | v4 | 0.6186 | 0.7297 | 0.9139 | 0.7110 |
| Qwen2.5-VL-3B | v3 | 0.6057 | 0.6622 | 0.9324 | 0.6880 |
| Qwen2.5-VL-3B | v4 | 0.5977 | 0.6757 | 0.9679 | **0.6952** |

与 v3 相比，v4 的 Omni 综合分数约下降 1.03 个百分点（按表中四舍五入值计算），Qwen3-VL 下降 0.91 个百分点，Qwen2.5-VL 提高 0.72 个百分点。v4 内部表现最好的模型是 Omni，Score 为 0.7185。三个模型的各轮综合分数如下，均随训练轮次增加而提高。

| 模型 | 第 1 轮 | 第 2 轮 | 第 3 轮 |
| --- | ---: | ---: | ---: |
| Qwen2.5-Omni-3B | 0.6994 | 0.7168 | **0.7185** |
| Qwen3-VL-4B | 0.6898 | 0.7095 | **0.7110** |
| Qwen2.5-VL-3B | 0.6589 | 0.6882 | **0.6952** |

训练与模型选择完成后，使用三个最佳模型分别对官方测试集进行推理。每个模型均输出完整的 734 条预测，样本顺序与官方一致，无重复、缺失、空字段或推理错误，全部输出成功解析为 JSON。测试集未提供真实标签，因此以上性能表均来自本地验证集；Kaggle 公开榜反馈单独列于下文。

## 四、结果分析

过采样对 Qwen2.5-VL 的主要收益来自不确定性判断。该模型正确识别的冲突样本由 49/74 增加到 50/74，对一致样本输出确定判断的数量由 552/592 增加到 573/592。两项指标的改善抵消了 Macro-F1 从 0.6057 降至 0.5977 的影响，使综合分数从 0.6880 提高到 0.6952。这一结果体现了情感分类与不确定性判断之间的具体权衡：v4 在该模型上获得更高的综合分数，v3 则保留了更高的情感分类 Macro-F1。

Omni 的情感分类和一致样本判断有所改善，但冲突识别准确率从 0.7432 降至 0.6892，正确识别的冲突样本由 55 条减少到 51 条，综合分数随之下降。Qwen3-VL 的 Macro-F1 基本持平，冲突识别数量由 56 条减少到 54 条，一致样本校准率也略有下降。两个模型的结果说明，在已有损失加权的基础上增加冲突样本频率，并未带来更高的冲突识别准确率。仅凭本组结果还无法确定下降的具体原因，后续可通过采样倍率与损失权重的组合对照，分析两者的作用。

本次比较保持了相同的训练轮数，过采样同时增加了训练总量：Omni 的优化步数由 630 增至 714，两个 VL 由 396 增至 468。因此，结果反映的是“两倍冲突采样、原有损失权重、训练三轮”这一完整设置的表现。验证集同时用于模型选择，实验结论适用于本次验证条件；进一步比较采样机制时，可固定优化步数，并使用多个随机种子检验结果的稳定性。

## 五、实验结论

本实验完成了冲突样本两倍过采样下的三模型微调与评估。该设置将 Qwen2.5-VL 的综合分数提高到 0.6952，提升主要来自一致样本校准率和冲突识别准确率；Omni 与 Qwen3-VL 的综合分数分别为 0.7185 和 0.7110，低于各自的 v3 结果。当前实验中，Omni v3 仍以 0.7288 获得最高综合分数。后续实验应围绕不同模型分别选择采样倍率和损失权重，并结合情感分类与不确定性判断的指标变化确定训练方案。

## 七、代码与复现入口

- 数据清洗和模态策略：[data/README.md](../../data/README.md)。
- 数据转换：`scripts/prepare_sft_data.py`，默认使用单问题监督。
- 重采样注册：`scripts/prepare_resampled_sft_data.py`。
- 字段损失实现：`scripts/task_balanced_loss.py`。
- 配置：`configs/sft/<model>/qlora_sft_v4_resample2x.yaml`。
- 训练：`scripts/run_sft_training.sh`。
- 按验证 Score 选择 checkpoint：`scripts/select_sft_checkpoint.py`。
- 生成式验证和测试：`scripts/run_sft_inference.sh`、`scripts/evaluate_sft.py`。

在准备好单问题训练/验证文件、媒体、模型与兼容环境后，从仓库根目录执行：

```bash
python scripts/prepare_resampled_sft_data.py
bash scripts/run_sft_training.sh qlora configs/sft/qwen25omni/qlora_sft_v4_resample2x.yaml 0
```

已有交付 adapter 时无需重训；推理时使用相应 v4 配置并显式指定实际
`ADAPTER_PATH`，按原运行记录设置 NF4/BF16。权重计划存放于团队私有模型仓库
[BUAA-AI/qwen25omni-sft](https://huggingface.co/BUAA-AI/qwen25omni-sft)，该地址
仅作为交付入口，本文未核验权重是否已上传。原始课程数据不随权重发布。
